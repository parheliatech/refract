VITURE Pro XR — the two buttons

The Pro XR has exactly two physical controls, both on the underside of the right arm: a single Mode button and a two-way + / − rocker. Everything else — brightness, volume, colour, the rear shade, screen-off — comes from short, double, triple and held presses of those two.

Compiled from strings in the Pro XR firmware image (N6PL 07.0.03.013, Apr 2025), the per-version changelog returned by cloud.viture.com, and SpaceWalker 1.8.6. Confidence is marked per row. Not official VITURE documentation.

The Mode button

A single click toggles the electrochromic shade — the shutter behind the lenses that blacks them out for an immersive picture or clears for see-through. The button also sets an internal state (func_key_mode) that decides which quick setting the rocker adjusts, and it is the way into the binocular-alignment mode. It does not switch 2D / 3D — that follows the video source and the SpaceWalker setting.

Single

Toggle the electrochromic shade (the rear shutter) — blacked-out ↔ see-through. The display stays on either way. This is the film only; a full screen-off is hold − (below). It does not change 2D / 3D.

Triple

Enter eye-axis / binocular convergence adjustment. Then use + / − to shift how the left and right images converge — tune it for viewing comfort.

The + / − rocker

Short clicks nudge the active quick setting; holding either side opens or triggers a bigger function. Brightness and volume each have nine steps (they were seven before firmware 07.0.03.005). Which one a bare click changes depends on the Mode-button state above and isn’t fully spelled out in these sources.

Click + / −

Step the active setting up / down — brightness or volume, or the current on-screen menu. Inside the colour-scheme menu, the same clicks cycle schemes.

Hold +

Open the Colour Scheme menu — True Color, Vivid, Warm, Cold, Film. Cycle with single + / − clicks; an on-screen prompt shows the selection. “Film” was added in 07.0.03.012.

since 07.0.03.003 · Jul 2024changelog

Hold −

Turn the screen off and clear the electrochromic film. Audio keeps playing — the glasses become plain audio glasses. Press any button to wake.

since 07.0.03.012 · Feb 2025changelog

Recovery mode

Hold L+ and L− together while plugging the USB-C cable in. The glasses come up in bootloader mode so an update tool can re-flash them.

Use this if a firmware update fails and the glasses stop displaying. Source: SpaceWalker’s own recovery instructions.

What software can see

No button press reaches a connected computer as an event. Every press is handled inside the glasses; a host app only ever sees the result after the fact.

Host can read back

  • Current brightness level
  • Current volume level
  • Display mode (2D / 3D)
  • Display distance and size

Host cannot tell

  • That any button was pressed
  • A tap from a hold, or single from triple
  • Anything the Mode button’s menus did
  • When the glasses were put on or taken off

Notes

Firmware matters. This reflects N6PL 07.0.03.013_20250422, the newest Pro XR release. Earlier firmware lacks the triple-click alignment mode (07.0.03.006), the colour-scheme menu (07.0.03.003), the Film scheme and hold-− screen-off (07.0.03.012), and 9-level brightness/volume (07.0.03.005).

Related changelog items that aren’t button gestures: the glasses self-calibrate gyro bias and yaw drift when left flat for a few seconds (07.0.03.008); “Pin Mode” screen-locking was reworked (07.0.03.003); VITURE Pro Neckband support landed in 07.0.03.010–011.
